# Firmar PDF

Herramienta de una sola página para firmar PDFs desde el celular o la PC. Todo corre en el navegador: el PDF no se sube a ningún servidor.

## Uso
1. Abrí `index.html` en el navegador (doble clic, o desde el link publicado).
2. **Abrir PDF** → elegí el archivo.
3. **Firma** → dibujala con el dedo/mouse, o subí una foto de tu firma (el fondo blanco se vuelve transparente). Queda guardada en el dispositivo para la próxima.
4. Tocá en la página donde va. Arrastrá para mover, esquina azul para agrandar, ✕ para borrar.
5. **Texto / Fecha** → agrega fecha de hoy, aclaración, DNI, etc.
6. **Descargar firmado** → genera `<nombre> - firmado.pdf`.

Nota: es una firma visual (imagen estampada), no una firma digital con certificado.
